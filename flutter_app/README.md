# SmartGrade Android
تطبيق Flutter أصلي بواجهة عربية RTL يتصل بخادم SmartGrade الحقيقي. لا يستخدم WebView ولا بيانات دخول تجريبية.

## البناء والتشغيل
ثبّت Flutter 3.44.0 وJava 21 وAndroid SDK وفق دليل Flutter الرسمي، ثم من جذر المستودع:
```sh
python scripts/prepare_flutter_android.py
cd flutter_app
flutter pub get
flutter analyze
flutter test
flutter run --dart-define=API_BASE_URL=https://your-domain.example/api
```

يمكن ترك API_BASE_URL فارغًا وإدخال عنوان الخادم في شاشة الدخول. استعمل HTTPS النهائي دون تحويلات.
مع Caddy المرفق العنوان ينتهي بـ /api، وعند الاتصال المباشر بـ FastAPI لا تضف /api.
على محاكي Android فقط يسمح debug بـ http://10.0.2.2:8000 عند تمرير --dart-define=ALLOW_HTTP_DEV=true.
إصدار release يرفض HTTP حتى لو مُرر هذا المتغير.

## الوظائف
- دخول المؤسسة والأدوار، وتغيير كلمة المرور الإلزامي، وتذكر الجلسة اختياريًا في التخزين الآمن.
- إنشاء اختبارات متعددة الأسئلة والمعايير، أو OMR من20 سؤالًا وأربعة بدائل.
- صور الكاميرا والمعرض واستعادة اختيار الصورة بعد إغلاق Android للنشاط.
- رفع بمفتاح idempotency ثابت لإعادة المحاولة، ومعاينة مصغرة محمية بنفس جلسة المستخدم.
- استخراج OCR عبر عامل المهام، توزيع الإجابات على الأسئلة، تبرير وأدلة لكل معيار، واعتماد المعلم.
- تعارض المراجعات409 يحتفظ بالمسودة، مع تحميل أحدث نسخة بطلب صريح.
- تصدير XLSX/CSV/PDF، وتقارير كبيرة عبر عامل المهام.
- خروج أو انتهاء الجلسة يتخلص من الشاشات الخاصة. لا تُخزن كلمة المرور.

تبدأ اقتراحات النموذج معطلة. يلزم إعداد المشغل وسياسة المؤسسة والموافقة على الطلب والتكلفة.
المسودات في ذاكرة الشاشة، وتُفقد عند إنهاء التطبيق أو انتهاء الجلسة؛ احفظ الإجابات قبل المغادرة.
المعاينة لا تغير أصل الصورة؛ يتحقق الخادم من حد16 مليون بكسل ونوع الملف الحقيقي.

## APK والجودة
Workflow "Verify release" يبني APK debug لاختبار الأجهزة، ويرفعه كملف Android-test-apk.
ثبّت app-debug.apk على جهاز اختبار؛ هو بناء داخلي بتوقيع debug، وليس إصدار متجر.
لبناء release وقّع بمفتاح مؤسستك خارج المستودع وفق دليل Flutter الرسمي. لا يوجد توقيع إنتاجي افتراضي.
التحقق الآلي يشمل التحليل والاختبارات وبناء Android واتصال عميل Dart بخادم محلي فعلي ببيانات اصطناعية.
لا يثبت ذلك اختبار كاميرا جهاز حقيقي أو دقة OCR/LLM العربية. لا توجد نسبة دقة مُقاسة.
وكيل Google Colab الخاص ليس عنوان خادم صالحًا لتطبيق الهاتف؛ انشر FastAPI عبر HTTPS وفق docs/deployment.md.
