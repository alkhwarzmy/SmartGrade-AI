# SmartGrade Android — مساحة عمل محلية

يفتح التطبيق افتراضيًا مباشرة دون حساب أو رابط أو خادم. بعد تثبيت APK تعمل الوظائف التالية دون إنترنت:

- اختبارات MCQ من 1 إلى 50 سؤالًا، وقالب A4 مطابق بصيغتي PNG وPDF.
- قراءة التظليل بواسطة OpenCV على الهاتف، مع مراجعة واعتماد المعلم.
- استخراج النص العربي بمحرك Tesseract ونموذج العربية المضمّنين داخل التطبيق.
- اختبارات مقالية متعددة الأسئلة والمعايير؛ توزيع الإجابات، التقدير اليدوي، واعتماد الدرجات.
- حفظ الاختبارات والصور والنتائج مشفّرة على الجهاز، وتصدير Excel/CSV/PDF.
- نسخة احتياطية مشفّرة بكلمة مرور، قابلة للاستعادة في مساحة فارغة.

**التقييم المقالي محليًا يدوي.** لا يوجد نموذج لغوي محلي يقترح درجات المقالات. راجع OCR خصوصًا خط اليد؛ لا توجد نسبة دقة مقاسة. لا تُنشأ بيانات تجريبية عند التشغيل.

## البناء

تتطلب مرحلة البناء إنترنت لتنزيل Flutter 3.44.0 وJava 21 وAndroid SDK والتبعيات. التشغيل بعد التثبيت محلي:

```sh
cd flutter_app
flutter pub get
flutter analyze
flutter test
flutter run
flutter build apk --debug
```

المصادر الأصلية لـ Android موجودة في المستودع. النموذج العربي يُنسخ من APK عند أول استخراج، ولا يُحمّل من الشبكة. تتوفر نسخة المؤسسة القديمة اختياريًا للمطور عبر `--dart-define=APP_MODE=remote` وتتطلب خادم HTTPS وحسابًا. إعداد API_BASE_URL وحده لا يبدّل الوضع المحلي.

## حفظ العمل

افتح أيقونة «البيانات والنسخ الاحتياطي» في الصفحة الرئيسية. احتفظ بنسخة خارج الهاتف وكلمة مرور من 12 إلى 256 حرفًا؛ فقدانها يمنع استعادة النسخة. حد محتوى النسخة 64 MB. الاستعادة ترفض استبدال مساحة تحتوي اختبارات لحماية البيانات.

حذف التطبيق أو مسح بياناته يحذف العمل المحلي ومفتاحه. لا توجد مزامنة تلقائية أو استيراد تلقائي لسجلات الخادم. التقارير المصدّرة ملفات عادية؛ اختر مكانًا مناسبًا لحفظها. المسودات غير المحفوظة داخل شاشة المراجعة تُفقد عند إغلاق التطبيق؛ احفظ النص والإجابات واعتمد الدرجات.

## التحقق والتوزيع

Workflow **Verify release** يشغّل التحليل، واختبارات Flutter، واختبار عميل المؤسسة مع API فعلي، ويبني APK داخليًا. مهمة **offline** تشغّل محاكي Android مع تعطيل الشبكة وتمنع إنشاء عميل HTTP داخل التطبيق، وتختبر OpenCV وOCR العربي الفعليين والحفظ والتصدير والاستعادة وفتح التطبيق دون رابط.

الملف **Android-test-apk / app-debug.apk** بناء داخلي للاختبار بتوقيع debug. إصدار المتجر يحتاج مفتاح توقيع وإجراءات نشر خاصة بالمالك. اختبار المحاكي لا يثبت جودة صور كاميرا هاتف حقيقي أو دقة الخط العربي اليدوي. التفاصيل في [دليل التشغيل المحلي](../docs/ANDROID_OFFLINE_AR.md).
