شُغّلت نسخة commercial بحساب مؤسسة اصطناعي، وخادم FastAPI وعامل OCR فعليين، ومتصفح Chromium. التقرير والصور تستخدم بيانات اصطناعية فقط؛ لم يُنشأ خادم دائم ولم تُشغَّل جلسة داخل حساب Google الخاص بالمستخدم.

اجتاز [اختبار الواجهات الفعلي](https://github.com/alkhwarzmy/SmartGrade-AI/actions/runs/45062246125) **25 فحصًا**:
الدخول، إنشاء اختبار من خمسة أسئلة عبر API، فحص الصورة ومعاينتها ورفعها، فتح المراجعة مباشرة، البحث في الأوراق، OCR الفعلي، حفظ وتوزيع الإجابات، منع التصحيح على نص غير محفوظ، اعتماد المرجع 17/30، تنزيل XLSX/CSV/PDF والتحقق منها، عرض الهاتف بعرض 390 بكسل والتنقل بقائمته، ثم إعادة تشغيل العمليات والتحقق من بقاء الدرجة.

راجع [التقرير الآلي](evidence/runtime-report.json) لمعرفة source_commit المختبر ونتيجة كل فحص، و[دليل الواجهات](../../docs/COMMERCIAL_WORKSPACE_AR.md) للصور والخطوات. أُجري التشغيل السابق قبل تحسين الواجهات في workflow 45058946890 وكان يشمل 19 فحصًا؛ التقرير الحالي يشمل فحوص الواجهة الإضافية.

**17/30 درجة أدخلها فاحص المراجعة وفق المرجع، وليست توقعًا صادرًا عن النموذج.**
تحقق الواجهات يعطّل طلبات النموذج الخارجية والمدفوعة صراحةً. أكد المستخدم أن إعداد مزوده في Colab Secrets، ولا يمكن لعملية GitHub قراءة Secrets الخاصة بحساب Google.

## تجربة نموذج المستخدم

افتح one_model_colab.ipynb في Colab بحسابك.
شغّل التجهيز، وأدخل MODEL_NAME عند الحاجة؛ يستطيع الدفتر قراءته من SMARTGRADE_LLM_MODEL أو LLM_MODEL.
المفتاح يُقرأ من SMARTGRADE_LLM_API_KEY أو LLM_API_KEY مع منح هذا الدفتر حق القراءة.
فعّل APPROVE_ONE_REQUEST عند الموافقة على إرسال العينة الاصطناعية وتكلفة طلب واحد، ثم شغّل الخلية الثانية.
يقارن محرك المشروع الحقيقي النتيجة بالمرجع 17/30 ولا يعيد الطلب تلقائيًا.
لا يطبع المفتاح أو يحفظه في التقرير، ولا ينشئ حسابًا أو يعتمد درجات أو يغير بيانات مؤسستك.
حالة واحدة لا تثبت نسبة دقة عامة.

## إصلاح اكتُشف بالتشغيل السابق

كان فحص المنفذ يرفض إعادة تشغيل Streamlit على المنفذ نفسه بعد توقفه بسبب TCP TIME_WAIT.
أُضيف SO_REUSEADDR لفحص المنفذ، مع استمرار رفض مستمع نشط.
اختبار اتصال TCP حقيقي وفحص إعادة تشغيل كامل بالمتصفح يثبتان الإصلاح.
