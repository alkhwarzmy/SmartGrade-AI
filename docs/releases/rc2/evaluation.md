# مسار جودة الذكاء الاصطناعي

التنفيذ البرمجي للتقييم جاهز؛ جمع بيانات حقيقية وتحكيمها لم يُنفذا لعدم توفر عينات مصرح بها ومصححين. لا تدريب أو إرسال خارجي من الأداة، ولا رقم دقة مستحدث لهذه النسخة.

ابدأ بالعينات المقترحة في الخطة:200 ورقة OMR، و 300 منطقة OCR/HTR، و 100–200 إجابة مقالية بمصححين مستقلين. هذه بداية تغطية وليست اعتمادًا إحصائيًا؛ تُسجل العتبات والتغطية وفواصل الثقة مع المقيم قبل قياس الاختبار.

الأداة محلية:

```bash
python -m scripts.evaluate_dataset --input /private/references.json --output /private/aggregate.json
```

مثال شكل ملف، بعينة اصطناعية للتنسيق فقط:

```json
{
  "authorized": true,
  "source_kind": "synthetic",
  "source_disjoint": true,
  "preregistered_thresholds": {},
  "samples": [
    {"id":"s1","writer_group":"writer-1","source_group":"exam-1","split":"test","kind":"ocr","reference":"الماء مهم","prediction":"الماء مهم"}
  ]
}
```

استخدم`real_authorized` فقط لبيانات ذات إذن موثق لدى الجهة؛ هذا الحقل تصريح المشغل ولا يثبت الإذن قانونيًا. لا تضع أسماء أو أرقام طلاب حقيقية في مفاتيح المجموعات؛ استخدم معرفات مستعارة. املأ`preregistered_thresholds` قبل تثبيت مجموعة الاختبار، واحتفظ بإثبات الإذن خارج Git.

التحقق يرفض المعرفات المكررة ووجود الكاتب نفسه في أكثر من train/validation/test، ويرفض تسرب المصدر عندما`source_disjoint=true`. اختر تصميم الفصل بحسب السؤال التربوي؛ لا تنقل العينة بين المجموعات بعد رؤية النتيجة.

- OCR: `reference` و`prediction` نصان؛ CER/WER خامان ومطبعان، مع بيان قواعد التطبيع في الكود. طابق الناتج المطبع مع الاستخدام الفعلي؛ إزالة التشكيل/اختلافات الألف قد تخفي أخطاء ذات أهمية لبعض المواد.
- المقالات: `reference` درجة المصحح الأول، و`rater2` درجة مستقلة، و`prediction` درجة المقترح، و`maximum` الحد نفسه لجميع عينات الملف. يُقاس اتفاق البشر أولًا، ثم MAE/QWK والاختلاف الشديد. لا يُقرب سلم كسري تلقائيًا للحصول على QWK.
- MCQ: مرجع 20 اختيارًا، وتنبؤ 20 اختيارًا أو`null` لرفض الورقة. يعرض القبول والرفض والأخطاء بين الإجابات المقبولة؛ يحتاج التقرير العلمي لاحقًا تفصيل الفراغ/التعدد وفواصل الثقة حسب المرجع.

الناتج مقاييس تجميعية فقط، ولا ينسخ نصوص الإجابات. `accuracy_certified=false` دائمًا؛ الحساب وحده لا يقر اعتمادًا علميًا أو تجاريًا. رفض صورة غير موثوقة يبقى سلوكًا مطلوبًا حتى مع أدوات القص والتدوير.

قرار التجربة الحالي: اعتماد المعلم النهائي إلزامي. لم تُستبدل Tesseract بنموذج HTR غير مقاس، ولم تُدعَم لغات/مواد أو أنماط خط يد بإعلانات دقة غير مختبرة.
