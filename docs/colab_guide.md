# تجربة SmartGrade AI على Google Colab

لتشغيل الحسابات والصلاحيات وبياناتك الفعلية، استخدم [دفتر المؤسسات ودليله](institution_colab.md). بقية هذه الوثيقة تصف دفتر demo القديم للتجربة دون حسابات.

دفتر Colab في إصدار المؤسسات يعمل صراحةً بوضع demo دون حسابات، للتجربة ببيانات اصطناعية. النسخة التجارية المحمية تُشغّل على الخادم وفق operations.md؛ لا يُستخدم هذا الدفتر لاستضافة عملاء.

## فتح الدفتر

[افتح SmartGrade مباشرة في Colab](https://colab.research.google.com/github/alkhwarzmy/SmartGrade-AI/blob/main/notebooks/SmartGrade_Colab.ipynb).

أو افتح `notebooks/SmartGrade_Colab.ipynb` من GitHub واضغط Open in Colab، أو نزّل الملف وارفعه عبر File → Upload notebook. إذا كان المستودع خاصًا، يلزم وصول حسابك إليه؛ ويمكن رفع الدفتر نفسه إلى Colab لأنه يتضمن كود المشروع كاملًا دون حاجة إلى clone أو GitHub token.

اختر Runtime → Change runtime type → Python 3 / CPU، ثم Runtime → Run all. لا حاجة لاشتراك Colab مدفوع أو GPU لتشغيل الوظائف الأساسية، لكن توفر الجلسات ومدة بقائها يخضعان لسياسة Google.

## ما تفعله الخلايا بالترتيب

| الخطوة | الوظيفة | هل تتطلب تدخلك؟ |
|---|---|---|
| 1 | تعريف مسارات المشروع والبيانات والبيئة الافتراضية | لا |
| 2 | فك المصدر المضمن بعد فحص SHA-256 والمسارات | لا؛ تتوقف عند اختلاف ملف موجود بدل استبدال تعديلاتك |
| 3 | إنشاء Python مستقل وتثبيت التبعيات وTesseract وخطوط العربية | قد يستغرق عدة دقائق |
| 4 | استعادة نسخة ZIP سابقة | اختيارية ومعطّلة افتراضيًا |
| 5 | تشغيل اختبارات الوحدات والتكامل والواجهة | مفعلة افتراضيًا |
| 6 | توليد قالب A4 وعينات MCQ اصطناعية | لا |
| 7 | إعداد مزود LLM من Colab Secrets | اختياري ومعطّل افتراضيًا |
| 8 | تشغيل Streamlit وعرضه داخل iframe لوكيل Colab | تظهر مساحة المعلم داخل الدفتر |
| 9 | إيقاف التطبيق وحفظ نسخة متسقة للتنزيل أو Drive | اختر download أو drive عند الحاجة |
| 10 | إيقاف الخادم دون حذف بيانات الجلسة | اختياري ومعطّل افتراضيًا |

كل خلايا الدفتر Python عادي بلا أوامر shell متداخلة أو مفاتيح مضمنة. مخرجات الدفتر المنشور فارغة، ولذلك لا يتضمن نتائج جلسة مستخدم أو روابط وكيل جلسة سابقة.

## تجربة MCQ

1. أنشئ اختبار اختيارات بالمفتاح الافتراضي `A B C D` مكررًا خمس مرات.
2. نزّل العينة الاصطناعية من التطبيق أو افتح لوحة ملفات Colab عند `/content/SmartGrade-AI/outputs/demo` لتنزيلها.
3. ارفعها في التطبيق برمز تجريبي، ثم راجع القراءة واعتمد النتيجة.
4. افتح النتائج وصدّر Excel أو CSV. المتوقع للعينة الكاملة 20/20 بالمفتاح المذكور، وهي عينة اختبار برمجي لا تقدير للدقة الواقعية.

## الإجابات المقالية وOCR

أنشئ سؤالًا مقاليًا ومعايير مجموع حدودها يساوي الدرجة الكاملة، وارفع صورة مقصوصة لإجابة واحدة. شغّل OCR المحلي أو أدخل النص يدويًا، ثم راجع النص واحفظه قبل التصحيح. أدخل درجات المعايير وتبريرها واعتمدها بعد المراجعة.

يُستخدم ملف `ara.traineddata` المضمن من Tesseract الرسمي مع ترخيصه. جودة التعرف على خط اليد لم تُعتمد؛ الاختبار الحقيقي الذي نُفذ محليًا كان على نص عربي مطبوع اصطناعي. تعذر تثبيت Tesseract لا يمنع بقية الوظائف.

## مزود LLM

أضف سرًا في Colab باسم `SMARTGRADE_LLM_API_KEY` ولا تكتبه داخل الخلايا أو GitHub. امنح هذا الدفتر حق قراءة السر من لوحة Secrets. في الخطوة 7 أدخل اسم النموذج وعنوان المزود، ثم فعّل `ENABLE_REMOTE_GRADING` و`APPROVE_API_COST` فقط عند الموافقة على الإرسال والتكلفة. أعد تشغيل الخطوة 8 لتطبيقها.

لا يرسل إعداد المفتاح طلبًا. يتطلب كل طلب موافقة أخرى داخل صفحة المراجعة، ويُرسل النص والسؤال والإجابة النموذجية والمعايير فقط. لم تُنفذ طلبات مدفوعة أثناء إعداد المشروع، ولم يُقاس اتفاق المزود مع المعلمين على بيانات مستقلة.

## حفظ البيانات واستعادتها

المسار `/content/smartgrade-data` مؤقت داخل جلسة Google Colab؛ ليس جهازك الشخصي. انتهاء الجلسة قد يمسحه. قاعدة SQLite الحية لا توضع على Google Drive لأن SQLite/WAL يعتمد على خصائص ملفات وأقفال لا تُضمن على Drive المربوط.

للحفظ، غيّر `BACKUP_ACTION` في الخطوة 9:

- `download`: إيقاف التطبيق، إنشاء ZIP، وطلب تنزيلها إلى جهازك.
- `drive`: العملية نفسها ثم ربط Drive بموافقتك وحفظ ZIP في `MyDrive/SmartGrade-AI/backups`.
- `none`: لا إيقاف ولا نسخ ولا ربط Drive.

تحتوي النسخة قاعدة البيانات والصور وسجل المراجعة وبصمات SHA-256، دون الأسرار أو السجلات التشغيلية. ZIP غير مشفر من التطبيق؛ اختر مكانًا مصرحًا وآمنًا لحفظ بيانات الطلاب. النسخ لا يحذف البيانات الحالية. لاستئناف العمل شغّل الخطوة 8 مجددًا.

للاستعادة في جلسة جديدة، فعّل `RESTORE_BACKUP` في الخطوة 4 واختر نسخة تخصك، مع بقاء مجلد البيانات فارغًا. يُفحص الحجم والمسارات والروابط والبصمات وسلامة SQLite والصور المرتبطة قبل الاستعادة، وتُرفض محاولة استبدال بيانات حالية. بصمات الملفات تحقق السلامة ولا تثبت أن مصدر الأرشيف موثوق.

## الواجهة والاتصال

يستخدم الدفتر `google.colab.output.serve_kernel_port_as_iframe` وفق واجهة Google الرسمية. لا يستخدم ngrok أو Cloudflare Tunnel ولا ينشئ رابط نشر عام. عنوان وكيل الجلسة يضاف إلى إعداد عنوان متصفح Streamlit، مع إبقاء حماية CORS وXSRF مفعلة. لم نستخدم `serve_kernel_port_as_window` لأن Google تصفها في مصدرها الرسمي بأنها مهجورة بسبب تغييرات أمان المتصفحات.

إذا لم يظهر iframe، تحقق من اتصال Runtime وسياسات حسابك أو المتصفح، ثم أعد تشغيل الخلية. السجل داخل `/content/SmartGrade-AI/.colab/streamlit.log`. لا تُطبع المفاتيح في واجهة التشغيل، ولا تدخل السجلات في حزمة المصدر أو النسخ الاحتياطية.

## إعادة توليد الدفتر بعد تعديل المشروع

```bash
python -m scripts.build_colab_notebook
python -m scripts.validate_colab_notebook --execute-smoke
python -m ruff check .
```

مولّد الدفتر يستخدم قائمة ملفات صريحة، ويستبعد بيانات التشغيل والمفاتيح وبيئات Python والمخرجات وGit والدفتر نفسه لمنع تضمين أسرار أو تضمين متكرر. يحتوي SHA-256 على الإصدار المضمن، وتُرفض الحزمة القديمة إذا اختلفت عن المصدر المحلي أثناء التحقق.

## حدود التحقق

نُفّذ فك الدفتر وإعادة فكه واختبار حفظ التعديلات وتشغيل جميع اختبارات المشروع من المصدر المستخرج **محليًا**. اختُبر تشغيل Streamlit وإيقافه والنسخ والاستعادة فعليًا محليًا. لم تُنفذ جلسة Google Colab مسجلة بحساب المستخدم، ولا ربط Drive أو قراءة Secrets أو عرض iframe داخل Colab حقيقي؛ هذه الخطوات تتطلب تشغيل الدفتر من حسابك. تبقى قيود جودة الخط اليدوي والتصحيح الآلي موثقة في evaluation_report.md وlimitations.md.
