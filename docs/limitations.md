# حدود إصدار المؤسسات 1.0.0-rc1

- هذا مرشح تجربة تجارية مُدارة، وليس شهادة جاهزية لإطلاق عام أو ضمان دقة/امتثال/SLA.
- حسابات وصلاحيات وعزل مؤسسات موجودة. لا يتضمن SSO أو MFA أو استعادة عبر البريد أو تسجيلًا ذاتيًا أو بوابة دفع/فوترة/تحصيل.
- التشغيل التجاري على Linux/قرص محلي/مضيف واحد. لا يدعم SQLite موزعة أوNFS/Drive أو autoscaling بين عقد. Colab وضع demo للتجربة وليس استضافة عملاء.
- حصص الخطط حدود منتج وليست نتائج اختبار أحمال. مساحة رفع الصور تُفحص، لكن نمو قواعد البيانات وسجل التعديلات والنسخ يحتاج مراقبة وتشغيلاً بسياسة احتفاظ.
- OMR v1 فقط:20×4 وصورةPNG/JPEG واحدة، بعلامات واتجاه صحيحين. لا قوالب حرة ولا PDF مرفوع ولا دمج صفحات/طلاب تلقائيًا أو دفعات خلفية.
- Tesseract خط أساس عربي مطبوع؛ لا يوجد HTR معتمد لخط اليد أو CER/WER على صور طلاب حقيقية.
- LLM اختُبر بعقد HTTP محاكى فقط؛ لا تقييم مستقل لاتفاق الدرجات مع المعلمين. المعلم يراجع كل اعتماد مقالي. سماح المشغل والمؤسسة والمراجع مطلوب قبل الإرسال/التكلفة.
- التقارير المعتمدة Excel/CSV وPDF عربي. PDF ملخص لا وثيقة موقعة رقميًا؛ حد2000 نتيجة، والتنزيل داخل الواجهة10MB، والـAPI الموثق للتقارير الأكبر.
- المدير الذي يملك الخادم والملفات يمكنه تعديل النظام؛ سلسلة بصمات السجل ليست أرشيفًا قانونيًا خارج سيطرته. سجل الدرجة ذري داخل المؤسسة، بينما الحدث المركزي في معاملة منفصلة وقد يتأخر/يفقد عند انهيار بين المعاملتين.
- الحذف منطقي يشمل الورقة وصورها وتاريخها الحالي، لا محوًا جنائيًا ولا حذف نسخ احتياطية. أداة الاحتفاظ dry-run افتراضيًا، ولا يوجد scheduler تلقائي أو تشفير ZIP من التطبيق.
- تهيئة الهوية ذات إصدار1 وترفض قاعدة أحدث؛ لا توجد سلسلة ترحيلات موزعة أو Postgres/Alembic. استيرادMVP يُبقي المصدر ويرفض استبدال مؤسسة قائمة.

قبل أول استخدام ببيانات عميل: أكمل التقييم الأمني والتربوي واستعادة بيانات بالحجم المستهدف، واضبط TLS والنسخ والمراقبة واتفاقية معالجة البيانات والتراخيص والتسعير والعقد. لا تنشر نسب دقة أو التزامات خدمة لم تُقَس أو تُتفق.
