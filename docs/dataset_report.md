# تقرير مصادر البيانات

## AR-AES

المصدر المطلوب: https://huggingface.co/datasets/Rnghazawi-NLP/AR-AES

أُجري فحص HTTP فعلي للرابط `https://huggingface.co/api/datasets/Rnghazawi-NLP/AR-AES`. لم يصل الطلب إلى الخدمة؛ رفض وكيل الشبكة اتصال CONNECT برمز 403 (curl exit 56، HTTP service code 000). لذلك لم تُفحص الأعمدة أو الترخيص ولم تُنزّل بيانات. لا نفترض أن المصدر نفسه غير متاح أو يرفض الوصول؛ القيد المشاهد في بيئة التنفيذ.

## KHATT

المصدر المطلوب: https://catalog.ldc.upenn.edu/LDC2015T23

واجه فحص الرابط القيد الشبكي نفسه. لم يتم التحقق من شروط الترخيص أو تنزيل المجموعة. لا توجد بيانات KHATT ضمن المستودع، ولا محاولة لتجاوز الترخيص أو قيد الشبكة.

## بيانات MCQ

القالب ومولد العينات محليان. الصور الناتجة موسومة `SYNTHETIC TEST DATA`. اختبارات الدوران والإضاءة والمنظور لا تعادل اختبار تصوير حقيقي. لا توجد صور طلاب حقيقية مضمّنة.

## نموذج اللغة المحلي لـOCR

تم تنزيل `ara.traineddata` من مشروع Tesseract الرسمي:
https://raw.githubusercontent.com/tesseract-ocr/tessdata_fast/main/ara.traineddata

ترخيص Apache 2.0 محفوظ في `assets/tessdata/LICENSE`. SHA-256:
`e3206d3dc87fd50c24a0fb9f01838615911d25168f4e64415244b67d2bb3e729`.

هذا ملف نموذج، وليس مجموعة تدريب متاحة لإعادة التوزيع على أساس KHATT. لا يثبت دعمه للنص العربي صلاحيته لخط اليد. الاختبار المحلي المنفذ نص عربي مطبوع اصطناعي.

## العينات المحلية

توفر `python -m scripts.prepare_data` استيراد ملف JSON محلي للتحقق من العينات. يحتفظ بالنص المرجعي والسؤال والإجابة النموذجية والمعايير ودرجات المصححين المستقلين. يمنع مسارات الصور خارج مجلد الملف، ويكشف تكرار نفس محتوى الصورة بين التقسيمات بواسطة SHA-256.

لا تُجرى عملية تدريب أو تقسيم تلقائي، ولا يكشف هذا الفحص جميع أشكال التسرب الدلالي أو الصور المختلفة للإجابة نفسها. يجب فصل الطلاب والأسئلة/المصادر حسب تصميم التقييم قبل أي تدريب مستقبلًا. لا يرسل المستورد بيانات إلى خدمات خارجية.

## خط PDF المضمن

يستخدم PDF التجاري ملف DejaVuSans.ttf من حزمة DejaVu في بيئة النظام، لدعم العربية مع إعادة تشكيل واتجاه bidi. ترخيص التوزيع والاعتمادات من الحزمة محفوظ في assets/fonts/LICENSE.txt. فُحص عرض PDF عربي فعليًا، ولا يثبت ذلك جودة التعرف أو التصحيح.
