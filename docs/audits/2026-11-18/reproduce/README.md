من جذر المستودع، داخل بيئة Python 3.11 أو أحدث مع متطلبات `requirements.lock`:

```bash
python docs/audits/2026-11-18/reproduce/probes.py
python docs/audits/2026-11-18/reproduce/performance.py
python docs/audits/2026-11-18/reproduce/omr_robustness.py
```

- `probes.py`: ست ملاحظات على النسخة المفحوصة، منها حالتان بحقن فشل. يتوقع السلوك الحالي ليؤكد إعادة إنتاج الملاحظة؛ بعد إصلاح المنتج يجب تحويل الحالات إلى اختبارات منع رجوع تتوقع السلوك الصحيح. نجاح هذا السكربت يعني تأكيد الملاحظات، وليس اجتياز المنتج لها.

- `omr_robustness.py`: تحويرات للقالب الاصطناعي نفسه. لا ينتج تقدير دقة مستقلًا لصور امتحانات حقيقية.
