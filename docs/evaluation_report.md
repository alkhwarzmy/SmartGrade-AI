# تقرير التحقق الفعلي

## البيئة

Python 3.12.14، SQLite، CPU، Chromium محلي، Tesseract مع ملف العربية المضمن. جرى تثبيت متطلبات `requirements.lock` في بيئة افتراضية نظيفة مستقلة، ثم تشغيل مجموعة الاختبارات فيها. لم يُستخدم GPU أو API مدفوع أو صور طلاب حقيقية.

## الاختبارات الآلية

اجتازت المجموعة الأساسية 35 اختبارًا؛ وبعد إضافة دعم Colab أصبحت المجموعة **44 اختبارًا**. تشمل:

- MCQ: إجابة مفردة، فراغ، تظليل متعدد، تظليل ضعيف غير واضح؛ دوران ±5 درجات مع هامش يحفظ العلامات؛ تدرج إضاءة؛ منظور وتصغير؛ رفض الاتجاه المقلوب وفشل المحاذاة.
- التخزين: حفظ واسترجاع بعد فتح اتصال جديد، منع تحديث بإصدار قديم، سجل مراجعة، حذف الصور والسجل المرتبط.
- المقالات: حدود المعايير ومجموعها، رفض NaN والدرجات السالبة أو الزائدة والدليل المختلق والمعايير الناقصة والمكررة، بقاء المقترح غير معتمد، إلغاء الاعتماد عند تغيير النص.
- المزود: حظر الاتصال دون الموافقات، والتحقق من JSON، وأخطاء HTTP والمهلة والمخرجات غير الصالحة عبر MockTransport. **هذه اختبارات تكامل محاكاة، وليست تشغيلًا حيًا لمزود LLM.**
- الأمان والتقارير: رفض الملفات غير المقبولة والمسارات الخارجة عن التخزين، تصدير المعتمد فقط، حفظ العربية ومنع صيغ جداول البيانات.
- الواجهة: إنشاء الاختبار والتنقل بين الصفحات واعتماد MCQ وإدخال درجات مقالية عبر Streamlit AppTest.
- OCR: تنفيذ Tesseract فعلي على نص عربي مطبوع اصطناعي؛ واختبار التعطيل الصريح.
- العينات المحلية: حفظ درجات المصححين المستقلين وكشف تكرار محتوى الصورة بين التقسيمات.

اجتاز Ruff فحص الشيفرة، واجتاز Git فحص whitespace. المخرجات محفوظة في `docs/evidence/`.

## رحلة مستخدم فعلية عبر Chromium

نجح `python -m scripts.browser_smoke` بخادم وقاعدة بيانات مؤقتين معزولين:

1. إنشاء MCQ من الواجهة ورفع صورة اصطناعية وقراءتها ومراجعتها واعتماد 20/20.
2. تنزيل Excel عبر زر الواجهة، وفتحه والتحقق من الدرجة و20 صفًا لتفاصيل الأسئلة والعربية.
3. إنشاء اختبار مقالي ورفع صورة عربية **مطبوعة اصطناعيًا** وتشغيل OCR المحلي فعليًا.
4. حفظ النص المصحح وإدخال درجات 3 و3 و1 يدويًا وفق ثلاثة معايير واعتماد 7/10.
5. تغيير النص بعد الاعتماد والتحقق من إلغاء النتيجة السابقة.
6. عرض صفحة المراجعة بعرض 390 بكسل والتحقق من ظهور التنقل العلوي وإخفاء القائمة الجانبية وغياب تجاوز أفقي على مستوى الصفحة.

أُصلحت أثناء هذه الاختبارات حالة إتاحة بدء المعالجة قبل اكتمال رفع الملف، وأضيف تأكيد مرئي لاكتمال حفظ النص واستخراجه. تقرير النجاح في `docs/evidence/browser-e2e-report.json`. لقطات التشغيل في `outputs/browser/` عند إعادة تنفيذ الاختبار.

## قياس MCQ الاصطناعي

شغّل `python -m scripts.evaluate mcq-synthetic` على 6 أوراق، بإجمالي 120 سؤالًا. النتائج المسجلة:

| الحالة | صحيح / إجمالي |
|---|---|
| اختيار واحد | 90 / 90 |
| فارغ | 18 / 18 |
| تظليل متعدد | 6 / 6 |
| غير واضح | 6 / 6 |

تطابقت الحالات والإجابات في 120/120 ضمن هذه العينات. احتاج 30/120 للمراجعة وفق تعريف الحالة، بمعدل 25%. زمن قراءة الأوراق الست في التشغيل المسجل نحو 0.316 ثانية، دون I/O أو واجهة أو مراجعة بشرية.

**البيانات مولدة من القالب نفسه وبنطاق اضطرابات محدود. لا تمثل هذه النتائج تقديرًا للدقة على امتحانات حقيقية أو صور هاتف مستقلة.** اختبارات الدوران والمنظور منفصلة ضمن المجموعة الآلية، وليست جزءًا من هذا الجدول.

## قياس OCR المطبوع

عينة اصطناعية واحدة: النص المرجعي «الماء ضروري للحياة». أعاد Tesseract النص نفسه؛ CER=0 وWER=0 على هذه العينة فقط، وفق مقارنة خام دون تطبيع عربي. الدليل في `docs/evidence/ocr-printed.json`.

**لا يوجد قياس CER/WER على خط يد عربي حقيقي، ولا نموذج HTR معتمد.**

## تقييم تصحيح المقالات

دوال MAE وQWK والاتفاق التام وضمن نقطة واحدة ومعدل الاختلاف الشديد منفذة ومختبرة حسابيًا. لا توجد بيانات بشرية مستقلة في البيئة لتقييم درجات النموذج؛ لذلك لا تُنشر أرقام جودة تصحيح مقالي.

يُحسب QWK للفئات الصحيحة فقط دون تقريب الدرجات الكسرية، ويكون غير معرّف عند انعدام التباين المتوقع. تعريف الاختلاف الشديد في هذه النسخة: فرق أكبر من `max(1, 20% من الدرجة الكاملة)`، ويُعاد الحد المستخدم مع النتائج. يجب اعتماد تعريف تربوي مناسب قبل أي مقارنة بحثية.

## ما لم يُختبر أو يُسلَّم

خط يد حقيقي، اتفاق درجات مزود LLM حي مع المعلمين، تحميل AR-AES/KHATT وترخيصهما، أحمال متزامنة كبيرة، مصادقة مؤسسية، نشر إنتاجي، وتصدير نتائج PDF عربي. هذه قيود معلنة وليست نجاحات مفترضة.

## تحقق دعم Colab

أضيفت 9 اختبارات فعلية: نسخ واستعادة قاعدة البيانات والصور والاعتماد والسجل، منع الكتابة فوق بيانات قائمة، رفض المسارات غير المسموحة والروابط والعبث بالبصمات، وتشغيل Streamlit محليًا وإيقافه مع فحص الصحة.

مدقق الدفتر يفحص Python لكل الخلايا والبصمة وتطابق المصدر المضمن وغياب البيانات والمخرجات الخاصة. وفُك المصدر إلى مجلد مؤقت، وأعيد فكه للتحقق من التكرار، ثم اختُبر رفض استبدال تعديل محلي، وتوليد قالب OMR، وتشغيل مجموعة الـ44 اختبارًا من المصدر المستخرج. لم تُستدعَ واجهات Colab للحساب أو Drive أو Secrets أو iframe في هذا التحقق المحلي. دليل الاستخدام في colab_guide.md وسجل التنفيذ في development_log.md.
