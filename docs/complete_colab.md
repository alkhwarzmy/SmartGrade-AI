# الدفتر الشامل
افتح notebooks/SmartGrade_Complete_Colab.ipynb في Google Colab، واختر Python 3/CPU ثم Runtime → Run all.
أدخل رمز المؤسسة واسمها وبريد المدير وكلمة مرورك المخفية عند الطلب. لا تحتاج GitHub token.
اضغط رابط الواجهة الذي يفتح في نافذة مستقلة، واسمح بالنوافذ المنبثقة إذا منعها المتصفح.

## جميع التحديثات
الدفتر يضم كود الخادم وStreamlit والتوثيق والاختبارات ومصدر Flutter Android كاملًا.
التشغيل commercial بحسابات فعلية وقاعدة فارغة، مع عزل المؤسسات وصلاحيات المدير والمعلم والمطلع.
أضف أو احذف الأسئلة المقالية بحرية. لكل سؤال إجابة نموذجية ومعايير ودرجات مستقلة.
احفظ نص الورقة، ثم وزع إجاباتها على الأسئلة واحفظها، وأدخل الدرجات والأدلة والتبريرات واعتمد الورقة.
ترك إجابة فارغة يعني صفرًا دون دليل، ومجموع الاختبار يساوي مجموع درجات أسئلته.
تغيير النص أو إجابات الأسئلة يلغي الاعتماد والاقتراح السابق. الحفظ المطابق لا يغير المراجعة.
المصدر الأصلي يبقى للمراجعة؛ لا يُوزع النص آليًا على الأسئلة دون تدقيق المعلم.
تقارير Excel تضم تفاصيل المعايير ودرجات الأسئلة؛ CSV/PDF يعرضان إجمالي النتائج المعتمدة.

## إذا تعثر رفع صورة
PNG/JPEG حتى10MB وحتى16 مليون بكسل. اختر من 1 إلى 50 سؤالًا للـMCQ؛ الصورة الكاملة يجب أن تطابق القالب الخاص بعدد أسئلة الاختبار.
علامة الخطأ الحمراء في أداة الرفع قبل بدء المعالجة لا تثبت مشكلة في OCR أو حجم الصورة.
افتح الواجهة من رابط النافذة المستقلة، ثم سجل الدخول مجددًا وارفع الصورة. لا تعطل XSRF أو CORS.
إذا استمر الفشل احتفظ بنص الخطأ الفعلي أو رقم HTTP من المتصفح، ولا تشارك كلمة المرور أو رمز الجلسة.

## حفظ المصدر والبيانات
آخر خلية اختيارية تنزل ZIP للكود الكامل بلا بيانات أو مفاتيح.
لحفظ الحسابات والصور والنتائج فعّل نسخة .sgb المشفرة في الخطوة9 واحتفظ بمفتاحها منفصلًا.
في الجلسة الجديدة استعد النسخة قبل إعداد الحساب. لا تضع SQLite الحية على Drive.
Colab يتوقف بانتهاء الجلسة ولا يصلح بحد ذاته لخدمة24/7.
مجلد flutter_app مضمن، وبناء التطبيق وتشغيله على Android موضح في flutter_app/README.md.
لا يُبنى APK تلقائيًا داخل جلسة Colab ولا يعمل تطبيق Android داخل واجهة Colab.
لا توجد نتيجة قياس منشورة لدقة خط اليد أو اتفاق الدرجات مع مصححين؛ اختبارات البرمجيات لا تقيس ذلك.
